# Validador gráfico de números telefónicos

Esta utilidad en Python ofrece una visualización detallada de un autómata que valida
números telefónicos en el formato 3-3-4 inspirado en el estándar de Estados Unidos.

## Requisitos

- Python 3.10 o superior (Tkinter viene incluido en las distribuciones oficiales).

## Ejecución

```bash
python main.py
```

La ventana permite ingresar un número, validar su estructura y observar paso a paso cómo el
autómata procesa cada componente del número.
